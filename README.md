# OmniFood Demo

A basic front-end demo website for a fictional healthy food delivery brand, OmniFood.

The project is built with plain HTML and CSS, and showcases a landing page layout with a fixed navigation bar, hero section, how-it-works flow, cities cards, testimonials, pricing plans, and a footer.

## Features

- Fixed top navigation with smooth scrolling links
- Hero section with call-to-action buttons
- How It Works section with numbered steps and app store links
- Our Cities section with card layout and branch details
- Testimonials section with customer quotes and profile images
- Pricing section with Starter, Pro, and Premium monthly plans
- Responsive layout for tablet and mobile breakpoints

## Tech Stack

- HTML5
- CSS3

## Project Structure

```text
OmniFood-Demo/
	index.html
	style.css
	README.md
	assets/
```

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.

Optional (recommended): Use the Live Server extension in VS Code for automatic reload during development.

## Customization

- Update images in the assets folder to change city/testimonial visuals.
- Edit text content in index.html for brand messaging and plan details.
- Adjust colors, spacing, and typography in style.css.

## Notes

This is a demo project focused on layout and styling. It does not include backend logic, authentication, or payment integration.
